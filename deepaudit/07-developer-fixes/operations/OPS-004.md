# A. OPS-004 — Missing and zero-discovery test runners create a false-green release path

## B. Severity

P1 — High. There is no executable regression safety net for a large security- and data-sensitive platform.

## C. Confirmation status

**CONFIRMED BY REPRODUCTION**

## D. Affected code locations

- [`backend/package.json:6-11`](https://github.com/bhaskarbeyond-creator/ime365-new/blob/df5902dd897ff8e7955a738ac580f2a0d0263d0d/backend/package.json#L6-L11)

## E. Current implementation

`npm test` calls a missing `scripts/run-tests-with-annotations.js` and exits 1. `npm run test:enterprise` points to an absent directory, exits 0, and discovers 0 tests/0 suites. No tracked `*.test.*` or `*.spec.*` files exist; `supertest` is also unmet locally.

## F. Reproduction evidence

Run both scripts from `backend/`. The first produces MODULE_NOT_FOUND; the second reports zero tests with exit 0. `npm ls --depth=0` reports missing supertest.

## G. Expected behavior

A clean install executes a nonzero, versioned suite; CI fails on missing runner, zero discovery, skipped critical suites, test failure, or dependency-install drift.

## H. Root cause analysis

Test scripts and dev dependency declarations survived after their files/install state were removed → one hard failure and one misleading zero-test success.

## I. Detailed technical solution

- Restore test sources and runner from authoritative history or create characterization tests around current contracts.
- Use Node test or the existing chosen runner consistently; fail when discovered test count is below an explicit floor.
- Pin/install all test dependencies and run from a clean lockfile install.
- Add unit, integration, database, security, export and Playwright jobs with clear blocked/live-provider separation.

## J. Proposed patch / code-level repair

```diff
- "test": "node scripts/run-tests-with-annotations.js",
- "test:enterprise": "node --test ... enterprise-test/*.test.js"
+ "test": "node --test test/**/*.test.js",
+ "test:ci": "node scripts/assert-test-count.js && npm test"
```
The exact command must follow restored source conventions; `assert-test-count.js` compares discovery to an approved minimum and critical-suite list.

**Patch verification:** DESIGN ONLY; no test sources existed to validate a patch.
