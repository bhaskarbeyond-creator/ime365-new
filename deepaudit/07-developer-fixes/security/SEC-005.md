## I. Detailed technical solution

- Restore clean test install and suites first.
- Update direct dependencies through supported compatible releases, then regenerate lockfile using the project package manager.
- Review transitive paths with `npm explain`; avoid untested forced overrides.
- Exercise request parsing limits/errors, trust proxy/IP attribution, SMTP flows, Firebase/grpc and abuse controls.
- Use an exception register with owner, rationale, compensating control and expiry only when no fix exists.
