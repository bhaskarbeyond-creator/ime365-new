# A. BUG-004 — Signup validation, verification copy and profile provisioning are inconsistent

## B. Severity

P2 — Medium. Users can receive misleading verification claims and identity/profile state can split on downstream failure.

## E. Current implementation

Weak-password checking occurs on blur rather than being guaranteed on submit; error mapping omits `auth/weak-password`; success copy always says verification email was sent while default config disables verification. Identity creation precedes awaited profile provisioning, without a complete recovery state.

## F. Reproduction evidence

Inspect submit/blur/error paths and default public configuration. Inject profile API failure after mocked identity success; the workflow lacks an explicit recoverable `IDENTITY_CREATED_PROFILE_PENDING` state.

## G. Expected behavior

Submit performs complete validation, copy reflects authoritative verification configuration, and partial identity/profile creation is resumable or compensated without duplicate accounts.

## H. Root cause analysis

Validation/copy and multi-system provisioning are separately implemented → submit and configuration state diverge; external identity side effect lacks durable local workflow state.

## I. Detailed technical solution

- Run the same password policy synchronously on submit and map provider error codes.
- Read authoritative auth configuration before claiming verification behavior.
- Create a provisioning state/idempotency key; identity success followed by profile failure becomes recoverable, not generic failure.
- On next login/registration retry, reconcile pending profile rather than creating another identity.
- Implement accessible error association per UIUX-002.

## J. Proposed patch / code-level repair

```js
const validation = validateSignup(form, authoritativeAuthPolicy);
if (!validation.ok) return showFieldErrors(validation);
const result = await provisionUserIdempotently(form, requestId);
showSuccess(result.verificationEmailSent
  ? 'Check your inbox to verify your email.'
  : 'Your account is ready.');
```
