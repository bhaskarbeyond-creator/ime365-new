The matrix proves declaration coverage, not behavioral correctness. Production qualification must add one generated runtime route manifest containing effective path, owner, authentication, authorization, validation schema, audit policy, rate limit and response schema, then compare it to an approved snapshot. Required tests are specified in [API_INTEGRATION_TESTS.md](../09-test-strategy/API_INTEGRATION_TESTS.md).
