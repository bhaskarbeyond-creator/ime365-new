## Required execution fixture

Each row must be rerun with:

1. a short ATS-safe synthetic profile;
2. a long multipage profile with all optional sections;
3. Unicode, punctuation, long URLs and missing-photo variants;
4. free/PRO/disabled entitlement states;
5. editor screenshot, browser preview, PDF raster, DOCX-converted raster and print PDF;
6. normalized text-order, font, margin, page-break, overflow and image comparisons.

A successful HTTP response or file-open check does not make a row pass. Every output column needs retained, synthetic-data evidence and independent visual review.
