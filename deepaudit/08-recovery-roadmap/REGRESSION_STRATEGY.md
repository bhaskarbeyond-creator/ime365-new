# Regression Strategy

## Pyramid

- Unit: policy, reset state machine, repository descriptor, template policy, validation and rendering transforms.
- Integration: disposable MariaDB, Firebase emulator, sandbox SMTP/payment/AI fixtures, Chromium egress container.
- API contract: all 459 declarations mapped to effective routes and approved schemas.
- E2E: auth, resume, cover, admin, export, enterprise and recovery journeys.
- Visual: five viewports plus editor/PDF/DOCX/print for 104 templates.
- Reliability: startup, migration failure, provider timeout, partial write, worker crash, load/soak and rollback.

Every required suite enforces nonzero discovery. Mock tests are labelled mock; only sandbox/live tests can certify integrations. Artifacts retain logs, screenshots, output documents, schema checksums and release manifests without personal data.
